# Weather App

## Descrição

O Weather App é uma aplicação que fornece informações meteorológicas em tempo real para qualquer localização no mundo. Utiliza a API OpenWeatherMap para obter dados precisos e atualizados sobre o clima.

## Funcionalidades

- Consulta de previsão do tempo atual
- Exibição de temperatura, umidade, velocidade do vento e condições climáticas
- Suporte para múltiplas localizações
- Interface amigável e responsiva

## Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript
- API OpenWeatherMap

## Instalação

1. Clone o repositório:
   ```bash
   git clone https://github.com/seu-usuario/weather-app.git
   ```
2. Navegue até o diretório do projeto:
   ```bash
   cd weather-app
   ```
3. Abra o arquivo `index.html` no seu navegador preferido.

## Como Usar

1. Abra o aplicativo no navegador.
2. Digite o nome da cidade desejada no campo de busca.
3. Clique no botão de busca para obter as informações meteorológicas.
